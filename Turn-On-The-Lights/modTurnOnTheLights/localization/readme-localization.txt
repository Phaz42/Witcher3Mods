Check which languages are supported on the Mod page on Nexus (under Posts tab in the
FAQ section of the stickied post at the top): https://www.nexusmods.com/witcher3/mods/7278?tab=posts&BH=0


If your language is not (fully) translated yet, you will see English text instead. If you want to help translate,
please report in this forum thread: https://www.nexusmods.com/witcher3/mods/7278/?tab=forum&topic_id=12955146


How to translate?

Open the file for your language under the localization folder with a text editor (e.g. Notepad).
Note: the files do not have an extension, so for example, the English file is called just "en".
You can rename the file to "en.txt" to open it, or just use the "Open With" dialog in Windows.

At the end of each line (after the last | character) you'll find the English text, replace this
with the translated text. Then save the file and share it in the forum thread linked above. You can
paste the contents of the modified file in your post there, or upload the file somewhere and give the link.

For example, to translate this line from English to Russian, change it from:

2117278011|        |preset_value_totl_mode_auto|Automatic

to

2117278011|        |preset_value_totl_mode_auto|Автоматический


Any help from translators is greatly appreciated and they will be credited! Thank you!
